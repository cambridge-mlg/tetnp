# Approximately Equivariant Neural Processes
An implementation of the NeurIPS 2024 paper ["Approximately Equivariant Neural Processes"](https://arxiv.org/abs/2406.13488).

## Dependencies
This code requires use of the [cambridge-mlg/tnp](https://github.com/cambridge-mlg/tnp) and [cambridge-mlg/tetnp](https://github.com/cambridge-mlg/tetnp) libraries.
